Rubylode Stats: page layout

Three layouts for the Overview tab, each in the Redmine 7 default theme and in Obsidian dark. Sample rows, invented names, real vendored Vega-Lite.

Variant A · Card grid

One compact filter bar, the active date range marked, then two-column cards that each name the question they answer.

Variant B · Numbers first

Card grid plus four summary tiles on top; the backlog tile carries an arrow and words, so colour is not the only signal.

Variant C · Filter rail

Filters, date range and selects live in a narrow left rail; tabs become a segmented control over tiles and the grid.
